## اختبار المتصفح الفعلي

Chrome في بيئة QA: فتح الصفحة، ملخص اليوم، إنشاء ملاحظة نصية ومشاهدة حفظها في صفحة المستجدات، الانتقال بين الأقسام مع بقاء النافذة العائمة، حساب المرافق وعلاقته المسجلة، تبديل إلى عمر، حساب اطلاع ومحاولة كتابة مرفوضة، تجربة عبارة ألم الصدر دون بلد مفترض

قياس صفحة iframe: العرض 390 (مساحة المحتوى 375)، و360 (345)، و320 (305)، لم يتجاوز scrollWidth عرض المحتوى. هذه **محاكاة عرض** وليست أجهزة iPhone/Android أو اختبار Safari

## قيود الإثبات

لم يُختبر صوت بشري أو مكالمة حيّة أو استماع بعد القفل؛ لا توجد عينة مزوّد. لا اختبارات Firebase Emulator في هذه الجولة، ولا فحص موثّق للقواعد المنشورة، ولا إشعارات حقيقية أو مستندات مرضى. لا تدّعي هذه الاختبارات أن محرك العبارات يغطي كل طارئ أو أن المخزن التجريبي جاهز للإنتاج
