# مراجعة الميكروفون والمساعد
المصدر: ملاحظات المستخدم على 9b68c34

## ما أصلح
- إزالة محدد CSS الذي كان يخفي النتائج والمساعدة العاجلة عند طي المدخلات
- توسيع الوكيل عند التحذير العاجل دون اتصال تلقائي، والبلد يحدده المستخدم
- حدود كلمات عربية لفحص الألم؛ أوامر الملف والموعد والمريض لا تحجب
- رسائل الدعم لا تمنع إرسال الطلب؛ أدوات العلاج تظل مقيدة
- منع الكتم والمقاطعة أثناء الخمول أو الاتصال
- تعطيل الضغط المتكرر أثناء الاتصال؛ الميكروفون النشط ينهي الجلسة، والمقاطعة زر مستقل
- تجاهل بقية صوت الدور الملغى حتى نهاية الدور؛ استمرار إرسال الميكروفون مع إلغاء الصدى
- تجهيز AudioContext في نقرة المستخدم قبل انتظار اختيار المثال؛ طلب الميكروفون بالتوازي مع استئناف الصوت؛ مهلة 15 ثانية وتنظيف المسارات المتأخرة
- التحول التلقائي للعائم في الجلسات النشطة فقط، مع الاحتفاظ بمكان البطاقة؛ التصغير اليدوي مستمر
- إخفاء التحكمات الصغيرة بلا جلسة وحفظ رسائل الخطأ عند إعادة الرسم
- أوصاف مخصصة للحالات، aria-pressed، وتصفير الموجة في حالات غير الاستماع
- Escape يعيد البطاقة الموسعة إلى المصغرة
- أخطاء المرفقات والأذونات لها رسائل عربية
- إغلاق الاتصال يعرض انتهاء الجلسة بدلا من خطأ اتصال عام

## حدود التحقق
اختبارات Node/JSDOM ومحاكاة الصوت فقط، لا إثبات لتجربة صوت أو لمس على iPhone/Android.
لا تغيير في قواعد Firebase أو Worker أو رسوم أو معالجة بيانات صحية حقيقية.

## المتبقي المنفصل
- استئناف الجلسة التلقائي مع الرموز المؤقتة وgoAway يحتاج اختبار اتصال طويل فعلي
- ترقية النموذج تحتاج تحقق التوفر والتكلفة والشروط قبل التفعيل
- AudioWorklet ومرشح إعادة أخذ العينات وتحسين التخزين الصوتي
- توحيد كل CSS وآلية إصدار كل الأصول تلقائيا
- مراجعة بصرية فعلية على iPhone وAndroid تشمل لوحة المفاتيح والإطار الموسع
