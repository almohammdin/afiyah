# مراجعة إصلاحات الدخول والصوت

## التغييرات
- فصل الحساب المستعاد عن جلسة الاستكشاف؛ إنهاء الاستكشاف لا يسجل خروج الحساب
- انتظار أول نتيجة مصادقة؛ إلغاء نافذة الدخول يبقي المثال في وضعه الصحيح
- منع إنشاء ملف مريض مؤقت في الاستكشاف، وإظهار طلب الدخول قبل إدخال بياناته
- استعادة المثال المحذوف بزر مستقل
- طلب الموافقة قبل تبديل الملف لبدء صوت المثال، مع العودة للملف السابق
- توحيد نسخة مراجع JavaScript وCSS المحلية، بما فيها الاستيراد الديناميكي، عند البناء وفي المصدر
- تطبيع التاء المربوطة في كاشف السلامة واختبارات للأشكال المتأثرة
- تمييز مقاطعة الخدمة عن الإيقاف المحلي وتعليق الصوت وتوقف الميكروفون؛ مسح أحداث الجلسة السابقة دون تسجيل محتوى المحادثة

## التحقق
npm run check: نجح
npm test: 73 اختبارا ناجحا
اختبارات الدخول تستخدم محاكاة Firebase واختبارات الواجهة تستخدم jsdom
لم يختبر تسجيل دخول Google فعلي أو صوت فعلي على iPhone أو Android في هذه الدفعة
لم تنشر أو تعدل قواعد Firebase أو Cloudflare أو الفوترة أو بيانات المرضى

## الحدود
سبب قطع الصوت بعد كلمات لم يثبت. تحسين التشخيص لا يعني إصلاح سبب الانقطاع
الكاشف الحالي لا يفهم النفي والسياق بشكل شامل. لم تضف الأنماط الواسعة المقترحة في التقرير
معالجة الملفات الصحية الحقيقية بالصوت ما زالت غير مفعلة
تغييرات الفرع للمراجعة قبل نشرها على الرابط الحالي
