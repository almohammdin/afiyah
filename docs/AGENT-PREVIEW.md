# عافية — معاينة الوكيل التفاعلي

تاريخ العمل: 2026-10-17

الفرع: `preview/interactive-care-agent`، مبني على `3a8a258f0d6929aa054cf2478cbe442a2b31035d`

هذه معاينة تنفيذية معزولة داخل مستودع عافية نفسه، وليست إصداراً منشوراً أو جاهزاً لبيانات المرضى. لم تتغير `main` أو إعدادات Firebase أو القواعد المنشورة أو بيانات الإنتاج. لم تُرسل إشعارات أو رسائل ولم تُفعّل فاتورة أو مفاتيح مزوّد. لا يحتاج الرجوع إلى ترحيل بيانات: أوقف خادم المعاينة وافتح النسخة الأصلية.

## التشغيل المحلي

يتطلب Node 24 وPoppler (`pdftotext`) وTesseract باللغة الإنجليزية لاختبارات الصور الاصطناعية فقط

```sh
npm ci
npm test
npm run dev
```

افتح `http://localhost:4173` على الجهاز الذي يشغّل الخادم. في بيئة المعاينة المدارة يستخدم `sites-preview start /absolute/path/to/checkout` بدلاً من تشغيل خادم آخر. `/preview/device.html` يحاكي عروض 390 و360 و320 و1280 بكسل في إطار، ولا يحاكي Safari أو Android أو نظام الصوت في الهاتف.

**لا تنشر هذا الخادم على الإنترنت**: اختيار الهوية هنا محاكاة حسابات معلنة، وليس Firebase Authentication. يحتاج نشر حقيقي إلى تحقق رمز Firebase على الخادم، وإعادة فحص العضوية لكل طلب، وتخزين خاص معتمد، ومراجعة أمن واختبارات Emulator، وتفويض مستقل.

## ما يعمل فعلياً

- المساعد في أعلى واجهة المتابعة نفسها، وصفحات السجل والتقويم والطباعة القائمة باقية
- واجهة عربية وهوية عافية وخطوطها وشعار نايف غير مرتبط بالسيرة الذاتية
- تصغير إلى نافذة عائمة عند التمرير أو تغيير القسم، مع كتم ومقاطعة وإنهاء وتوسيع
- تنفيذ نصي حتمي محدود للأوامر، وليس نموذج ذكاء اصطناعي مفتوح اللغة
- ملخص اليوم والأدوية والتقارير وملخص الزيارة، وإنشاء الملاحظات والمهام، ونموذج موعد، وتعديل السجلات عبر بطاقات المراجعة
- تسجيل الجرعات وتصحيحها، فصل وقت الحدث والموعد والتسجيل وهوية المدخل والمريض والمنطقة الزمنية
- أدوات خادم تتحقق من الصلاحية؛ مستخدم اطلاع لا يستطيع الكتابة ولو استدعى API مباشرة
- معاملات SQLite متسلسلة، مفتاح عملية محفوظ، منع تكرار الموعد بين مستخدمين، مراجعة تفاؤلية للتعديل، وسجل تدقيق وتراجع لا يطغى على تعديل أحدث
- رفع ملفات الاختبار الفعلية وتخزينها داخل مخزن المعاينة غير العام، واسترجاعها بعد تحقق هوية الملف وصلاحية التقارير
- استخراج نص PDF محلياً مع الصفحات وOCR محلي للصورة التجريبية، وعرض مصدر غير موثوق وحقول ناقصة، دون تلقيمه للأوامر
- رفض كل ملف لا يطابق بصمة عينات الاختبار، وعدم اعتماد جرعة أو جدول من صورة العلبة
- جدولة مستقلة عن الصوت كل 30 ثانية، قنوات محاكاة بموافقة المستلم، حالات اطلاع ومعالجة، بلا أي ناقل بريد أو push حقيقي
- مساعدة عاجلة متاحة دون نموذج، واختيار بلد صريح، وفصل 997 عن 937 وروابط اتصال يضغطها المستخدم فقط

## بنية الفصل

خادم المعاينة يعرض نفس `app.js` بعد تحويل الاستيراد في الذاكرة إلى `preview/adapter.js` ويضيف نقطة تركيب للمساعد. لم يُستبدل محول Firebase الأصلي. CSP المعاينة يمنع الاتصالات الخارجية، والخادم يحجب `data.js` و`config.js`. البيانات في `.preview-state/demo.sqlite` مستثناة من Git. لا تتضمن المعاينة أسراراً أو رموز وصول إلى Firebase

السياق يحتفظ بالمريض المحدد والمستخدم الحالي فقط داخل الجلسة؛ تبديل المريض يمحو الحوار والطلبات المعلقة ويوقف القراءة الصوتية القديمة. السجلات المنظمة هي مصدر الحقيقة. سياق الصوت مملوك لكائن مستقل عن عناصر الصفحة، فلا تنهي إعادة الرسم الجلسة. عند قفل الهاتف لا يوجد وعد باستمرار التسجيل

الملفات محدودة بالبصمات المعتمدة، وحجم الطلب محدود، والاستخراج بمهلة وبدون shell. هذا لا يغني عن فحص الملفات والعزل ومكافحة البرمجيات الخبيثة وسياسة الاحتفاظ في التخزين الإنتاجي

## المطلوب قبل أي تفعيل حقيقي

1. اختيار مسار مزوّد مسموح للبيانات الصحية لهذا الغرض، واتفاق معالجة/احتفاظ وموقع معالجة وموازنة وتفويض مستقل؛ لا ترسل مفتاحاً في المحادثة
2. تركيب ناقل المزوّد على الخادم بمخزن أسرار، وتحقق Firebase Admin من الهوية لكل طلب، مع عدم تعريض المفتاح للمتصفح
3. صلاحية قراءة إدارية محدودة للتحقق من القواعد المنشورة ومقارنتها بالنسخة المقصودة؛ أي نشر قواعد يحتاج إذناً مستقلاً
4. اختبار أصوات سعودية بعينات القائمة في `preview/provider.js`، وتقييم أسماء الأدوية و500/10/0.9 والأوقات، وعينة يسمعها نايف ويعتمدها
5. اختبار فعلي على Safari/iPhone وChrome/Android (ميكروفون، سماعات، مكالمات مقاطعة، قفل الشاشة، انقطاع الشبكة) قبل ادعاء التوافق
6. استبدال مخزن المعاينة بمخزن إنتاج معتمد وإجراء اختبارات قواعد ومرفقات وجداول، ومراجعة طبية للنصوص وقواعد السلامة، ثم موافقة نشر مستقلة

## رابط المعاينة المباشرة

أضيفت `preview/web/index.html` كنسخة متصفح قابلة للمشاركة من نفس فرع GitHub. تولدها `python scripts/build-share-preview.py`. تستخدم سجلات افتراضية في ذاكرة الصفحة، وتعيدها عند التحديث، وتحاكي الحسابات والصلاحيات محليا. لا تتصل بخادم السجلات أو Firebase أو مزود ذكاء، ولا تقبل ملفات المستخدم. عينات نتائج المرفقات محاكاة في هذه النسخة؛ الرفع والاستخراج الفعليان موثقان في المعاينة المحلية فقط. هذه النسخة لتجربة الواجهة والأوامر، وليست اختبارا لأمن الخادم أو تزامن جهازين
