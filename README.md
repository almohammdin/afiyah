# عافية | Afiyah

منصة عربية للجوال لتنظيم متابعة صحة أفراد الأسرة، بملفات مستقلة باسم المريض ومشاركة محددة لكل ملف.

الموقع: https://almohammdin.github.io/afiyah/

## حالة الإصدار 1.0

واجهة واحدة في جذر الموقع، تشمل متابعة اليوم والتقويم والملف الصحي وأرقام ملفات المستشفيات والمشاركة حسب صلاحيات الأقسام

الدخول مرتبط بمشروع Firebase المستقل لعافية، ولا تُنقل بيانات المرضى إلى GitHub

اختبارات الواجهة: `npm test`، واختبارات الصلاحيات في `tests/rules.test.mjs` باستخدام Firestore Emulator

تفاصيل التشغيل وحدود الوظائف في [RELEASE.md](RELEASE.md)
